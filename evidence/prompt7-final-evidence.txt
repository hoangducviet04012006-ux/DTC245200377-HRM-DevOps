Bước 7: Demo Hệ thống Log Loki & 4 Biện pháp Hardening (1.5 phút)
- Mở Grafana Explore (Loki):
  1. Chạy câu LogQL 1: {project="hrm", container="hrm-nginx"} xem luồng log.
  2. Chạy câu LogQL 2: {project="hrm", container="hrm-nginx"} |= "POST /api/auth/login" |= " 401 " để thấy ngay log đăng nhập sai ở Bước 3.
- Mở Terminal SSH trình bày 4 biện pháp Hardening:
  1. Non-root App: Chạy docker exec hrm-app id -> uid=1000(node).
  2. Cô lập mạng: ss -tulpn | grep 5432 chứng minh PostgreSQL không mở cổng ra host.
  3. Bí mật ngoài Git: git grep xác nhận không còn fallback default password trong mã nguồn.
  4. Phân quyền DB tối thiểu: Thử lệnh CREATE TABLE bằng role hrm_app_user -> Bị từ chối quyền; thử truy vấn users bằng role hrm_exporter_user -> Bị từ chối quyền.
